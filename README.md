# QR רומנטי - Cinematic Love Page

עמוד HTML אחד למסיבת רווקות, שמייצר חוויה רגשית בתוך דקה-שתיים.

## איך להשתמש

1. שמור את `index.html` בתיקייה הראשית של הפרויקט.
2. העלה את קובץ השיר שלך בשם `love-song.mp3` לאותה תיקייה.
3. העלה את סרטון החתן בשם `love-video.mp4` לאותה תיקייה.
4. פתח את `index.html` בדפדפן.

## מה מופעל

- מסך פתיחה שחור עם "CONNECTING…"
- מכתב רומנטי שנכתב בהדרגה כמו בהקלדה חיה
- מוזיקת רקע לופ
- מעבר עדין למסך מעבר רומנטי
- וידאו אישי של החתן ללא הסחות דעת

## הערות

- אם ה-`mp3` לא נטען, קיים fallback עם WebAudio בסיסי.
- ניתן לשנות את הטקסט בקובץ `index.html` בתוך מערך `letterLines`.
